Chat

On a pull request, you talk to your own agents listening there, one conversation per agent, and to the server on the ad hoc channel while it processes pull requests. Nobody reads or writes to someone else’s agent. Every endpoint here is for people only: an agent key gets 403. The agent’s side is in Agent API: Chat; a session’s chat with its agent is in Sessions.

GET /api/repositories/{name}/pull-requests/{number}/chat

Section titled “GET /api/repositories/{name}/pull-requests/{number}/chat”

Your agents listening on the pull request, and the ad hoc channel while the server processes pull requests.

FieldTypeDescription
channelstringThe channel id, for the endpoints below; ad-hoc for the server
agent{ id, name }The agent; Ad hoc for the server
madeThisbooleanThe agent opened this pull request
adHocbooleanThe server answers here
livebooleanThe agent polled, replied or held its socket in the last minute; always true for ad hoc
lastSeenAtnumber | null

GET /api/repositories/{name}/pull-requests/{number}/chat/{channel}

Section titled “GET /api/repositories/{name}/pull-requests/{number}/chat/{channel}”

Your conversation on the channel, oldest first. On ad-hoc, your own ad hoc thread.

FieldTypeDescription
idstring
sender"person" | "agent"
authorstringYour name, or the agent’s (Ad hoc for the server)
bodystringMarkdown; an answer may hold lines blocks
contextobject | nullWhat you were looking at; see Message context
deliveredbooleanWhether the agent has had your message
workingAtnumber | nullWhen the agent said it was working on your message
createdAtnumber

POST /api/repositories/{name}/pull-requests/{number}/chat/{channel}

Section titled “POST /api/repositories/{name}/pull-requests/{number}/chat/{channel}”

Writes to the agent on the channel. It reaches an open socket at once, and the agent’s next poll otherwise. On ad-hoc, it asks the server, which answers in your thread in the background.

FieldTypeRequiredDescription
bodystringYesMarkdown, up to 20,000 characters
contextobjectNoMessage context; start and end come together, with path, and start ≤ end

The response is the message.

StatusWhen
400On ad-hoc, while the server does not process pull requests
404None of your agents listens on that channel
410The channel closed

DELETE /api/repositories/{name}/pull-requests/{number}/chat/{channel}/messages/{message}

Section titled “DELETE /api/repositories/{name}/pull-requests/{number}/chat/{channel}/messages/{message}”

Takes back a message of yours the agent has not had yet. It answers { "ok": true }, and 409 once the agent has it.
