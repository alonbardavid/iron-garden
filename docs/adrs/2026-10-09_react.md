# React

Date: 2026-10-09

## Decision

Frontends are built with React.

## Why

React is the industry standard: mature and widely supported. It leaves room to pivot beyond
the web app — React Native, and other React-based non-web tech such as React Email — and to
move to SSR or SSG through a variety of tools.

Almost every popular library, including third-party integrations, ships React support; for
other frameworks (Vue, Angular) that support is hit and miss.

## Trade-offs

React is large and needs many other libraries to work, where Vue, Angular and Svelte ship
some form of signals and routing built in.

React is also poor at rendering pages/components from strings, unlike frameworks with string
templates. If the app pivots towards that, re-evaluate.
