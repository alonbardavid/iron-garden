# Drizzle

Date: 2026-10-09

## Decision

The database is accessed through Drizzle ORM. Migrations are hand-written SQL files in
`migrations/`, applied with wrangler (`wrangler d1 migrations apply`). drizzle-kit is not
used.

## Why

Drizzle is lightweight and easy to integrate inside Workers. It is geared more towards
writing SQL than towards a pure ORM, which gives agents the flexibility to write queries the
way they see fit, with fewer side effects from changing a model's properties.

The alternatives:

- **Sequelize** — too big, geared towards ORM-style use, and its typing ergonomics are
  complex.
- **TypeORM** — too big. Decorators are still the preferred path and the non-decorator
  ergonomics are complex. Its many options (Active Record vs Data Mapper, …) can confuse
  agents.
- **Knex / Kysely** — no ORM at all, which makes schemas hard to use and leaves agents room
  for mistakes that static types would easily catch.
- **Prisma** — relies on code generation, which agents don't always use well and which
  limits their flexibility. The company is very geared towards its cloud products, so a
  bait-and-switch is likely in the future.

Migrations use wrangler because Cloudflare's CLI supports them conveniently and we need few
migration features. Plain SQL is easy for agents to write.

drizzle-kit is not used because it generates migrations from the code schema. That is
complicated, especially when the schema is split across several places, and generators
tend to trip up AI — which mostly removes the need for them anyway. drizzle-kit also keeps
very large artifacts in git, and generating means cross-cutting concerns such as indexes
have to live in the code schema somehow.

## Trade-offs

- Sequelize is very mature, and its metaprogramming and plugins would allow a seamless
  integration between APIs and DB models.
- TypeORM is more mature, and its typing is usually more robust.
- Kysely is already used by better-auth.
- Prisma's ability to generate many kinds of code from the schema is very valuable, and it
  has good better-auth support.
- wrangler migrations are plain SQL with little flexibility. If more is needed, move to
  something like umzug.
